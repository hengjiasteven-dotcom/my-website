## 写在前面

这篇文章是一份完整的、未经删节的游戏设计文档。它记录了一款基于《来自深渊》世界观的同人文字游戏从零到一的全部设计思路——世界规则、状态模型、双骰判定、上升诅咒、遗物代价、隐藏人格、延期后果、单一真结局结构，以及如何把动画原片的前 50 分 36 秒忠实地转化为可玩的前章。

这不是一个"套了《来自深渊》皮的普通文字分支游戏"。它是一个先服从深渊世界规则、再让玩家在生存和执念之间慢慢滑向不同命运的叙事游戏。

整体分为两层：

- **长期完整版**：完整深渊系统 + 多层探索 + 单一真结局结构（设计文档已完成，尚未完全接进代码）

- **当前前章原型**：忠于原片的前章，为正式下潜建立情绪和人物（代码层已有完整雏形）

一句话概括：**先用忠于原片的前章建立情绪和人物，再在正式下潜章节里让诅咒、遗物代价、隐藏人格和单一真结局结构真正接管游戏。**

全文约两万字，建议收藏后阅读。

## 一、核心方向与世界规则

### 1.1 视觉层：四维公开值

前台只展示四个公开值，玩家一眼能懂：

- **元气**：体力、精神、伤病承受力、诅咒冲击后的可行动余量。低值表现：头晕、疼痛、疲劳、惊惧、行动迟缓

- **家底**：现钱、补给、装备、遗物余量、可动用的兜底资源。低值表现：缺粮、断药、装备破损、补给线紧张

- **人缘**：公会信誉、队友信任、底层人脉、情报网络、被施救概率。低值表现：求助困难、组队受限、情报滞后、被放弃

- **心气**：执念、目标感、继续向下的意志、面对深渊时不退缩的劲头。低值表现：退缩、动摇、失去方向

四个值统一范围 `0-100`：

| 区间 | 状态 |

|---|---|

| 0-20 | 濒危 |

| 21-40 | 吃紧 |

| 41-60 | 可撑 |

| 61-80 | 稳健 |

| 81-100 | 旺盛 |

**一个极其重要的设计**：心气不是越高越好。当 `心气 > 85` 且 `异化度` 或 `深渊注视` 偏高时，系统会逐步将其解释为"执念过载"，这会暗中提高坏结局概率。心气是一把漂亮的火焰——它可以照亮前路，也可以把你烧穿。

### 1.2 定死的世界规则

以下规则在系统层属于强约束，不被一般剧情轻易推翻：

1. **垂直上升 ≥ 300m** 必须进行一次诅咒判定

2. **水平移动**和**继续下潜**不触发上升诅咒

3. 越深层的诅咒，越偏向不可逆后果，而不只是数值损失

4. **笛级权限**决定可被公会承认的下潜深度，越级下潜后公会会降低甚至取消救援与备案支持

5. 强力遗物一定带代价，代价可以是元气、异化、人缘、心气甚至剧情旗标

6. 到达**第六层**以后，系统不再默认存在"常规意义上的回返"

7. 玩家越接近"看见深渊真相"，越接近"失去作为人离开的资格"

### 1.3 结局哲学

底层实际上只有两类结局：

- **TrueEnding**：唯一真正的生还结局

- **RuinEnding**：其余全部，区别只在于死法、消失方式、异化方式、是否留下名字

真结局不来自"最强""最深""最传奇"，而来自：

- 见过足够多的真相

- 没把所有人都当成通往深渊的工具

- 没让自己彻底被执念烧穿

- 在关键时刻承认"活着离开"比"抵达最深处"更难也更珍贵

**奖励的不是"最强、最深、最传奇"，而是有没有保住人性、回返意志，以及知不知道该为什么停下。**

## 二、状态模型

### 2.1 深渊专属显式状态

这些值不一定全部展示给玩家，但必须参与结算：

| 变量 | 含义 | 范围 |

|---|---|---|

| `current_layer` | 当前所在层数 | 0-7 |

| `current_depth` | 当前深度，单位 m | — |

| `whistle_rank` | 笛级：铃挂 / 赤笛 / 苍笛 / 月笛 / 黑笛 / 白笛 | — |

| `ascend_meter` | 自上次诅咒判定后累计垂直上升距离 | — |

| `wound` | 伤势 | 0-100 |

| `curse_debt` | 近期连续承受上升负荷后的残留负担 | 0-100 |

| `aberration` | 异化度 | 0-100 |

| `abyss_gaze` | 深渊注视——被深渊"看见"的程度 | 0-100 |

| `cash` | 现钱 | — |

| `supplies` | 抽象补给值，包含食水、绳索、药剂、火源等 | — |

| `relic_slots` | 可携带遗物位 | — |

| `bond_core` | 核心羁绊数量 | — |

| `pending_list` | 延期后果列表 | — |

| `flag_set` | 剧情关键旗标集合 | — |

### 2.2 深渊专属隐藏状态

这三个状态不属于 MBTI 维度，但会直接左右后期命运：

**H01 人性锚点（humanity_anchor）**：范围 0-100。由核心羁绊、是否把他人当工具、是否还能停下等因素决定。低值表现：逐渐失去对同伴痛苦的感知，开始把人视为"资源"或"障碍"。当降至极低时，系统会允许出现一些"高效但残忍"的选项——而这些选项往往通向坏结局。

**H02 回返意志（return_intent）**：范围 0-100。不是是否胆小，而是你是否还把"活着离开"当成一个值得守住的结果。这个值会在以下情况被侵蚀：连续多次选择"继续向下"而非"先保证能回去"；面对诱惑时习惯性忽略撤退选项；核心羁绊断裂。

**H03 执念热度（obsession_heat）**：范围 0-100。高时会推动玩家做出更极端的下潜选择。**关键设计**：执念热度高不是直接坏事，但它会改变选项的味道。同一个"继续深入"的选项，低执念时系统文本是谨慎的，高执念时文本会变得狂热——而玩家可能意识不到自己已经被推着走了。

### 2.3 开局推荐初始值

| 变量 | 初始值 |

|---|---|

| 元气 | 55 |

| 家底 | 45 |

| 人缘 | 50 |

| 心气 | 60 |

| wound | 0 |

| curse_debt | 0 |

| aberration | 0 |

| abyss_gaze | 0 |

| cash | 80 |

| supplies | 60 |

| bond_core | 1 |

开局不做问卷，而做"奥斯镇出生段 + 孤儿院/学徒期事件"。建议使用 8-10 个开局选择，围绕：跟谁亲近、面对危险先找人还是先自己扛、是否藏私、拿到遗物先上交还是先研究、面对强者时的态度、第一次下洞时遇险后的处理方式。

## 三、双骰判定系统

### 3.1 骰子结构

每次关键选择后摇两颗骰子：

- **势骰 d20**：负责本回合表层结果的强弱。展示给玩家。

- **影骰 d8**：负责余波、暗伤、诅咒回响、遗物副作用、隐藏变量偏转。展示给玩家。

### 3.2 入局规则

默认随机选一颗入局，概率因场景而异：

| 场景 | 势骰 | 影骰 |

|---|---|---|

| 镇内 / 准备 / 普通社交 | 85% | 15% |

| 探索 / 战斗 / 扎营 | 75% | 25% |

| 高压 / 诅咒 / 遗物使用 / 仪式 | 60% | 40% |

若满足以下任一条件，再向影骰额外偏移 10%：

- `curse_debt >= 40`

- `aberration >= 35`

- `abyss_gaze >= 50`

- 当前场景属于第 5 层及以下

### 3.3 倍率表

| 势骰 d20 | 倍率 | 影骰 d8 | 倍率 |

|---|---|---|---|

| 1-4 | 0.6 | 1 | 0.5 |

| 5-9 | 0.85 | 2-3 | 0.8 |

| 10-14 | 1.0 | 4-5 | 1.0 |

| 15-18 | 1.2 | 6-7 | 1.25 |

| 19-20 | 1.45 | 8 | 1.55 |

### 3.4 未入局骰的作用

未入局骰不改变本回合的公开主结果，只做以下事情：

- 提升或削弱诅咒后遗症

- 影响延迟事件烈度

- 影响队友是否记住你的行为

- 影响遗物是否"回头收债"

- 给隐藏变量追加 `±1 ~ ±2` 微偏转

## 四、公开值计算公式

### 4.1 即时变化

每个选项先定义基础向量：`Base = [元气, 家底, 人缘, 心气]`

即时变化公式= round(Base × 入局骰倍率 × 场景修正 × 层级修正)

**场景修正**：

- 默认 `1.0`

- 选项非常符合当前处境：`+0.1`

- 公开值已很低还强扛：`-0.1`

**层级修正**：

| 层 | 修正值 |

|---|---|

| 第 0-1 层 | 1.0 |

| 第 2 层 | 1.05 |

| 第 3 层 | 1.1 |

| 第 4 层 | 1.15 |

| 第 5 层 | 1.25 |

| 第 6 层 | 不走普通公开公式，交由特殊判定 |

**限制**：单回合单项变化建议不超过 `±18`，最终公开值限制在 `0-100`。

### 4.2 深渊状态影响

选项还会额外影响 wound、curse_debt、aberration、abyss_gaze、cash、supplies 等。示例：

- 启用高阶遗物强行开路：家底 +6，元气 -4，aberration +6，abyss_gaze +8

- 为救同伴逆坡攀升：人缘 +7，元气 -8，ascend_meter +350

## 五、上升诅咒判定

这是本作**最核心的世界机制**，也是整个游戏的系统心脏。

### 5.1 触发条件

每当 `ascend_meter >= 300`，立即触发一次诅咒判定，并执行 `ascend_meter -= 300`。若一次动作中连续上升 600m，则要判定两次。

### 5.2 诅咒强度

CursePower = 层级基础值 + 连续上升段数 + curse_debt修正 + scene_risk修正

**层级基础值**：

| 层 | 基础值 |

|---|---|

| 第 1 层 | 15 |

| 第 2 层 | 28 |

| 第 3 层 | 40 |

| 第 4 层 | 58 |

| 第 5 层 | 75 |

| 第 6 层 | 不使用普通数值，直接进入终末判定 |

**额外修正**：

- 每多一段连续上升：`+6`

- `curse_debt >= 30`：`+5`

- `curse_debt >= 60`：再 `+8`

- 高压、负伤、缺药、雨林毒雾等特殊场景：`+3 ~ +10`

### 5.3 抗性

CurseResist = 元气系数 + U03 + U04 + U09 + U10 + 遗物缓冲 + 队友支撑 + 入局骰修正

系统内部参考来源：元气、wound、U03 精神抗性、U04 诅咒耐受、U09 疼痛耐受、U10 恐惧阈值、是否有缓冲类遗物、是否被队友固定或照护。简化成分档：强抗、中抗、弱抗。

### 5.4 各层诅咒结果

#### 第 1 层

- **主要后果**：头晕、恶心、短暂反胃

- **系统效果**：元气 -4 ~ -10，wound +0 ~ +4，小概率附加"眩晕"

#### 第 2 层

- **主要后果**：剧烈头痛、呕吐、末端麻痹

- **系统效果**：元气 -8 ~ -16，wound +4 ~ +10，supplies -2，小概率附加"手脚失灵"

#### 第 3 层

- **主要后果**：平衡丧失、幻视、方向错乱

- **系统效果**：元气 -10 ~ -18，wound +8 ~ +14，追加"方向错乱"旗标，失败时可直接引发坠落检定

#### 第 4 层

- **主要后果**：撕裂剧痛、出血、行动崩溃

- **系统效果**：元气 -16 ~ -26，wound +15 ~ +25，aberration +4 ~ +8，追加"出血"或"内脏受损"

#### 第 5 层

- **主要后果**：意识混乱、自残冲动、情感钝化

- **系统效果**：元气 -14 ~ -22，心气 -6 ~ +4，aberration +10 ~ +18，humanity_anchor -8 ~ -16，追加"情感脱落""失控"或"自伤冲动"

#### 第 6 层

不再走普通数值伤害结算。一旦在第六层承受上升诅咒，进入**终末分流**：

- 直接死亡

- 生骸化

- 作为人归零

- 极少数特殊条件下触发隐藏真结局判定

### 5.5 诅咒余波

每次诅咒结算后，未入局骰还会额外造成一种余波：

- 旧伤复发

- 睡眠破碎

- 对某人产生依赖

- 对某层产生畏惧或着魔

- 遗物共鸣

- 深渊注视上升

这部分很适合做文本神秘感来源。

## 六、遗物系统

### 6.1 遗物分层

| 等级 | 定位 | 四要素合计 | 说明 |

|---|---|---|---|

| 三级 | 普通工具型 | +1 ~ +2 | 工具、照明、防护、辅助探索 |

| 二级 | 稳定功能型 | +2 ~ +3 | 轻度特殊能力，改变短期处境 |

| 一级 | 强力机制型 | +3 ~ +4 | 强力效果，附带一定代价 |

| 特级 | 改写场景型 | +2 ~ +4 | 强制附带强代价/稀有度/使用限制 |

### 6.2 遗物代价设计原则

每件遗物至少带一种代价：元气永久下修、aberration 增长、abyss_gaze 增长、bond_core 风险、某个关键 NPC 对你的观感改变、某条路线被锁死。

**核心原则：越方便的遗物，越容易在未来"收一次更大的债"。越接近奈落至宝，越不应该只是数值装备。**

### 6.3 可枚举的特殊功能池

`option_unlock` / `option_lock` / `block_attack_once` / `block_curse_once` / `reroll_d20` / `reroll_d8` / `teleport_checkpoint` / `teleport_surface` / `status_buff` / `status_debuff` / `route_override`

### 6.4 遗物完整清单（104 件）

#### 三级遗物（普通工具型）

1. **雾织纱**：人缘+1，心气+1。持有时解锁【贴壁潜行】；首次被侦测可重掷一次 d20

2. **微光苔囊**：元气+1。扎营时额外回复 1 元气；黑暗探索判定有利

3. **岩壁防滑缠带**：元气+1。攀爬类失败可重掷一次 d20

4. **深渊蓄水陶壶**：家底+2。水源匮乏场景不吃第一次补给惩罚

5. **耐寒绒织披肩**：元气+1，人缘+1。寒冷场景获得 2 回合【御寒：元气+1】

6. **警示鸣响螺**：人缘+1。遭遇伏击时可强制重掷一次 d8

7. **耐磨探窟靴底片**：元气+1。移动损耗减 1；解锁【长距折返】

8. **便携风干肉匣**：家底+2。休整时一次性为全队额外回复 1 元气

9. **荧光引路绳**：家底+1，心气+1。迷路类选项可改为安全版本

10. **湿气吸收麻布**：元气+1。潮湿场景第一次负面状态无效

11. **简易止血膏罐**：元气+1。一次性抵消一次流血类攻击或诅咒

12. **沙尘收集壶**：家底+1。干旱区域补给损耗减 1；可收集一次线索材料

13. **天气预测风信鸡**：心气+1。下一环境伤害场景提前知晓，并可重选一个准备选项

14. **恒温裹身毡毯**：元气+1。极寒或极热场景获得 2 回合元气+1

15. **深渊防潮皮囊**：家底+2。补给受潮失效一次可忽略

16. **防滑吸附靴垫**：元气+1。攀爬或湿滑判定有利

17. **除湿净化麻布**：元气+1。一次性解除潮湿、霉变状态；净化装备

#### 二级遗物（稳定功能型）

## 八、队友、羁绊与救援

### 8.1 人缘的真实作用

人缘不只是好感度，而是以下内容的总和：

- 组队许可

- 谁愿意借你物资

- 谁愿意替你挡一次上升

- 谁愿意带你进据点

- 你失踪后是否有人找你

- 你濒危时是否还有名字被记住

### 8.2 核心羁绊

系统区分普通关系和核心羁绊：

- **普通关系**：主要影响物资、情报、队伍协助

- **核心羁绊**：主要影响 humanity_anchor、白笛线祭品条件、隐藏真结局、某些看似"英雄"的坏结局会不会真的被执行

### 8.3 救援概率

RescueChance = 人缘基础 + 当前层救援可能 + 核心羁绊加成 - 越级惩罚 - 深度惩罚

深度越深，哪怕人缘高，也不保证还能被救回来。

## 九、笛级与白笛

### 9.1 越级后果

当玩家进入超过当前 `whistle_rank` 官方许可的深度时：

- 公会救援事件权重下降

- 官方备案失效

- 人缘中的公会信誉、高阶探窟家认可更难增长

- 某些镇内售卖、晋升和交付路线暂时锁闭

- 若死亡或失踪，系统更倾向以"无名探窟家"的方式收束

### 9.2 白笛与魂之誓约

白笛资格不是单纯数值奖励，而是道德与命运节点。系统条件：

- 黑笛前置

- 极深层关键旗标

- 至少 1 个足够深的核心羁绊

- 触发魂之誓约决断事件

> **白笛资格在表面上看似是"最强成长路线"。但在底层结局逻辑里，它往往更接近坏结局入口，而不是默认好结局入口。**

## 十三、真结局与坏结局结构

### 13.1 表层设计

游戏表面上可以有多种"大结局标签"：

- 白笛加冕

- 绝界行

- 深层共生

- 真相抵达

- 无名凯旋

- 永失其名

玩家会以为这些只是不同结局类型。

### 13.2 底层真实结构

底层实际上只有两类：

- **TrueEnding**：唯一真正的生还结局

- **RuinEnding**：其余全部，区别只在于死法、消失方式、异化方式、是否留下名字

### 13.3 真结局隐藏条件

真结局不要来自"最强""最深""最传奇"，而要来自：

- `humanity_anchor >= 55`

- `return_intent >= 45`

- `obsession_heat <= 70`

- `aberration < 60`

- `bond_core >= 1`

- 拥有若干真相旗标

- 在白笛或绝界相关节点，没有走"彻底献祭他人换通行"的路线

> 这些条件不要在 UI 里直说。玩家只会从文本里感觉到：有些"很燃"的选择，系统却越来越冷；有些"像退缩"的选择，反而被世界轻轻放过。

### 13.4 坏结局的处理方式

坏结局不要总用"你死了"直白收尾。更适合用：

- 只剩笛声回到镇上

- 遗物被打捞，人名无人提起

- 某个队友再也不谈起你

- 你在上升中失去了最后的名字

- 记录停在某一层的回音

- 某座祭坛前多了一只沉默的白笛

**玩家知道自己失败了，但系统只暗示，不明说。**

## 十五、终章判定

终章不要直接判"最深层就赢"。建议终章先判这几个问题：

1. 你是否已经知道"继续向下"真正意味着什么

2. 你是否仍把某个人当成可以牺牲的代价

3. 你是否还有回返意志

4. 你是否已经被深渊看见到无法抽身

如果这些判定不达标，即便进了最深层，也只是**更华丽地通向坏结局**。

## 十六、原片版前章设计

### 16.1 前章边界

本稿按《来自深渊 启程的黎明》HD 原片前 **50 分 36 秒** 内容整理，视为项目里"原片版前章"的唯一基线。

已完成：世界观开场、莉可与雷格的初识、镇内保密与调查、莉可对母亲与深渊的向往再次强化、正式下深渊之前的最后准备与进入前缘。

本质是：**世界开场 → 主角与关键伙伴登场 → 核心关系建立 → 动机确认 → 进入深渊前的临界点**。

### 16.2 核心设计约束

> **在正式下深渊之前，不触发基于四要素或隐藏维的特殊剧情分支。**

前章阶段只允许做三类变化：文本口吻变化、观察重点变化、轻度情报顺序变化。

不允许：因数值高低出现隐藏支线、因人格倾向改写原片事件顺序、在前章触发额外高难原创事故。

前章任务：**忠于原片推进、悄悄记录玩家、为后续难度扩展留底**。

### 16.3 前章五阶段

#### 阶段一：阿比斯与莉可身世（0:00 - 4:07）

建立阿比斯的历史与地位，交代奥斯因深渊而生，埋下莉可"出生于深渊奇迹"的命运底色。建议基本保持低互动。

#### 阶段二：奥斯日常与雷格登场（4:07 - ~15:00）

切到目前的奥斯与莉可日常，介绍孤儿院、公会、镇上孩子关系。在一次靠近深渊的行动里，雷格作为"异常存在"进入故事。这是前章里第一个真正可玩的段落。

**游戏化建议**：玩家可决定"先关注莉可的哪一面"，但最终都会走向雷格被发现。

#### 阶段三：镇内保密、调查与关系建立（~15:00 - ~33:00）

雷格被带入私密空间，朋友们围绕雷格的来历、身体、行为展开观察。确立"雷格是谜"这个核心钩子。这一段特别适合承接游戏自己的伙伴情报、轻度调查感、可查看的身体特征。

**游戏化建议**：可查看身体特征/机械构造/失忆状态，选择是否告知大人、先信谁、先问什么。但只能影响对话顺序和好感印象，不能改变主线结论。

#### 阶段四：关于母亲、深渊与出发动机确认（~33:00 - ~44:00）

莱莎相关传闻压到莉可面前。连接从"偶然相遇"变成"共同朝向深渊"。**这是整个前章最重要的精神中轴。**

**游戏化建议**：可以有多个"态度选择"，只记录玩家如何看待深渊、莱莎、失踪与归来、雷格的来历，不改变出发方向。

#### 阶段五：夜间行动、潜入与进入下潜前缘（~44:00 - 50:36）

从"说要去"过渡到"真的开始行动"。气氛切换成真正的冒险临界点。**适合作为前章的收束点。**

### 16.4 推荐场景拆分（20 场）

## 十九、这次重构后的核心区别

如果你只看公开四维，这次重构前后似乎没什么变化——还是元气、家底、人缘、心气，还是 0-100。但往深看一层，整个游戏的底层逻辑已经完全不同了。

### 系统驱动：从"四维推动剧情"到"深渊规则压着四维走"

以前的思路是：四维值高 → 解锁更好的选项 → 走向更好的结局。这是一种典型的成长游戏逻辑——数值越大，结果越好。

现在不一样了。四维值只是玩家"看起来怎么样"的外在指标，真正决定命运的是深渊规则：你上升了多少米、你被深渊看见了几次、你的异化度到了什么程度、你的人性锚点还剩多少。四维值被这些规则压着走，而不是反过来。

### 核心机制：上升诅咒成为整个游戏的系统心脏

在旧设计里，上升只是"往回走"这么简单。在新设计里，上升是整个游戏最危险的行为——每上升 300 米就触发一次诅咒判定，越深层的诅咒越不可逆，到了第六层甚至可以直接终结游戏。

这意味着：**玩家每一次选择"回去"，都不是安全的**。"活着离开"不是默认选项，而是需要付出代价、做出取舍、甚至做出牺牲才能争取到的结果。

### 心气：从"越高越好"到"可能烧穿你的漂亮火焰"

心气在旧设计里是一个单纯的正向值——有目标感、有执念、有干劲，这不好吗？在新设计里，心气高确实能支撑玩家走得更远，但当心气 > 85 且异化度或深渊注视偏高时，系统会把它解释为"执念过载"。这时候，表面上看起来"最勇敢"的选择，实际上可能正在把玩家推向深渊。

### 白笛与绝界行：从"默认好结局"到"高危坏结局入口"

在《来自深渊》的世界里，白笛是探窟家的最高荣誉。但在我们的游戏里，白笛资格的底层逻辑写得很清楚——它往往是坏结局的入口，而不是默认好结局。因为要拿到白笛，你必须在极深处做出极极端的选择，而那些选择几乎必然伴随着人性的损耗。

### 好结局条件：从"到最深处"到"知道什么时候停"

旧设计问的是"你能不能走到最深处"。新设计问的是：

- 你是否还把人当人

- 你是否还想要活着回来

- 你是否已经被执念烧穿了

- 你是否还在为了某个真实的目标前进，而不是为了"更强""更深""更传奇"而前进

唯一真正的生还结局，不奖励"最强"，奖励"清醒"。

## 写在最后

这份文档记录的不只是一个游戏系统，而是一种设计理念：**规则应该服务于世界的感受，而不是服务于数值的平衡。**

在大多数游戏里，数值是主角——你变强了，你能打败更强的怪，你能去更远的地方。数值是推动剧情的引擎。

在这个游戏里，深渊才是主角。深渊有它自己的规则：上升就要付出代价，越深越不可逆，强东西一定带毒，到了某个深度之后就不默认你还能回来。玩家的四维值、遗物、羁绊、甚至人格坐标，都在被这些规则推着走。你以为你在做选择，其实你在一个更古老的意志里挣扎。

在《来自深渊》的世界里，深渊不是关卡，而是命运。上升不是逃生，而是代价。遗物不是装备，而是交换。白笛不是勋章，而是赌注。而唯一的善终，不是走到最深处的人，而是走到最后还记得为什么回来的人。

这个游戏不会告诉你"你赢了"。它只会告诉你"你回来了"——然后让你自己去想，这一路上，你到底失去了什么，保住了什么，以及那些选择，值不值得。

如果你读到了这里，也许你已经准备好了。

那就下去吧。
