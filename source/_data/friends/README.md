# Friends Data

Place one JSON file per friend in this directory on the `friend-links` branch.

Suggested file name:

```text
example-blog.json
```

Example content:

```json
{
  "name": "Example Blog",
  "url": "https://example.com/",
  "avatar": "https://example.com/avatar.png",
  "description": "A short introduction.",
  "backlink": "https://example.com/links/"
}
```
